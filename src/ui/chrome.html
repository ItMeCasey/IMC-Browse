IMC Browse

General

Uses your graphics card to draw pages and decode video. Turn it off if you see flicker, black video or graphics-driver crashes. Changing it needs a restart.

Default 3600 (one hour). Hibernating tabs show a Zzz badge and wake when you click them. Tabs playing audio are never hibernated.

Toolbar

Drag items between the lists to show, hide or reorder them (or use the arrows and + / x buttons). Installed extensions can be added here too. The menu button always stays. Right-click the toolbar to open this page.

AI assistant

The panel opens the site you choose inside this browser, so it uses your normal login for that site: no API keys. Click the AI button in the toolbar (or Ctrl+Shift+A) to open it, and "Send page" to put the page text or your selection into its chat box. Nothing is sent until you click that button, and you press Enter yourself. Ghost tab pages are never sent. Some sites block or limit sign-in with Google or similar inside embedded browsers; if that happens, sign in with email on that site.

AI control (command line)

Lets a program on this PC (for example an AI agent such as Claude Code) run imc-browse ctl ... to open tabs, read page text, click, type, scroll and take screenshots. It only works for programs running as your Windows user, never remotely. Ghost tabs are invisible to it, there are no commands for passwords, cards or downloads, and every request is listed at imc://ai. A green dot on the AI button shows while it is on. Turn on JavaScript only if you trust the tool: it can read anything on pages you are signed in to. Run imc-browse ctl help for the commands.

Updates

Nightly builds are the newest changes, built every night when something changed. They are less tested than stable releases. You get an "Upgrade Available" notice when a newer one is out.

Checks for a new version every few hours, on the nightly channel if you are subscribed or the stable channel if not, and installs it automatically. Every update is signed and verified before it is installed, and you choose when to restart. With both switches off, the browser only checks when you click Check now.

Mouse gestures

Hold the right mouse button over a page, drag in a direction (or several: for example down then right), and release. A plain right-click still opens the normal menu.

Passwords

Import a CSV exported from Chrome, Edge, Brave, Firefox, Bitwarden or 1Password. Passwords are encrypted with Windows (DPAPI) for your user account before they are saved. The CSV itself is plain text: delete it after importing. Fill only works on HTTPS pages of the saved site and only when you click it.

Payment cards

Card numbers are encrypted with Windows (DPAPI) for your user account before they are saved. The security code (CVV/CVC) is never stored: you type it yourself at checkout. Details are only filled when you click Fill, only on HTTPS pages, and only in the page itself (checkout forms inside embedded payment frames cannot be filled).

Privacy & proxy

Secure DNS

Looks up website names through an encrypted HTTPS connection to the provider, so the network you are on cannot see or alter which sites you visit. The provider does see the names. Strict mode means sites will not load if the DNS server cannot be reached. Changing this needs a restart.

Proxy / VPN

Changing these restarts the browser and restores your tabs.
